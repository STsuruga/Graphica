# Graphica プラグイン実装バックログ

2つの100件提案(前回レビュー案 / Gemini案)を統合・重複排除し、**プラグインとして実装すべきもの**を抽出したリスト。全64件。
本体側は `Graphica_CORE_BACKLOG.md`、振り分けの根拠は `Graphica_INTEGRATION_REPORT.md` を参照。

## 前提

**このリストの大半は、現状のプラグインAPI(`register_fit_function` / `register_menu_action`)では実装できない。**
着手前に本体側 C-13(拡張ポイント)の該当項目が必要。各行の「要フック」欄に対応を示す。

## 凡例

- **難**: ★☆☆ / ★★☆ / ★★★
- **工数**: S 〜1日 / M 2〜5日 / L 1〜3週 / XL 1ヶ月〜
- **需要**: ◎ その分野なら全員 / ○ その分野で多数 / △ 限定的
- **出典**: A 前回レビュー案 / B Gemini案 / AB 両者
- **要フック**: 必要な本体側の拡張ポイント(C-13xx)

## 着手推奨プラグイン Top 8

本体の C-1301〜C-1303 が揃った直後に着手する順。

| 順 | ID | プラグイン | 理由 |
|---|---|---|---|
| 1 | P-805 | 元素・物理定数テーブル | 他パックの共通基盤。小さく作れる |
| 2 | P-101 | JCAMP-DX インポータ | メーカー非依存。1つで多くの装置をカバー |
| 3 | P-304 | UV-Vis パック | Tauc plot の需要が高く、実装が最も軽い |
| 4 | P-202 | スパイク除去 | Raman ユーザーには必須。単体で完結 |
| 5 | P-306 | 電気化学 CV パック | 実装が軽く、対象ユーザーが多い |
| 6 | P-201 | Shirley / Tougaard | P-301(XPSパック)の中核部分を先行 |
| 7 | P-401 | PCA | 追加依存なしで実装可能。分野横断で使える |
| 8 | P-303 | Raman / FT-IR パック | P-802(官能基DB)とセットで価値が出る |

**プラグインAPIの検証としても有効:** P-101(インポータ)、P-202(前処理)、P-304(解析+パネル)の3つが素直に書ければ、C-1301〜C-1303, C-1305 の設計は妥当と判断できる。逆に本体を触らないと書けない箇所が出たら、そこが設計の穴。
