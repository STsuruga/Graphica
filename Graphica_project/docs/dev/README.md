# 開発用資料

Graphica 本体の開発で使っている計画・引き継ぎ用の資料です。**アプリの使い方は
[Wiki](https://github.com/STsuruga/Graphica/wiki) を参照してください。**

| ファイル | 内容 |
|---|---|
| `CURRENT_STATE.md` | 現在の作業状況(セッション間の引き継ぎ用) |
| `RELEASE_CHECKLIST.md` | リリース手順 |
| `roadmap.html` | 機能一覧の通し番号チェックリスト |
| `Graphica_MASTER_SCHEDULE.md` | 開発トラックの全体計画 |
| `Graphica_SPEC.md` | アーキテクチャと機能の仕様まとめ |
| `Graphica_ROADMAP_PLUGIN_AND_GUI.md` | プラグインAPI・GUI刷新の段階別手順 |
| `Graphica_CORE_BACKLOG.md` / `Graphica_PLUGIN_BACKLOG.md` | 本体・プラグインのバックログ |
| `Graphica_INTEGRATION_REPORT.md` | バックログ分割の経緯 |
| `CORE_FEATURES_PROGRESS.md` / `PLUGIN_API_PROGRESS.md` / `GUI_MODERNIZATION_PROGRESS.md` / `PLUGIN_DEVELOPMENT_PROGRESS.md` | トラックごとの完了記録 |
| `gui_style_audit.md` | テーマ・配色の棚卸し(`screenshots/` の画像を参照) |

利用者・貢献者向けの資料は1つ上の `docs/` にあります(`plugin_development.md`、
テストカバレッジの `COVERAGE.md` / `COVERAGE_DETAILS.md`)。
