テーマカラー
テーマカラーは上のバーか、アプリ左下の ⚙ → テーマカラー で変えられます。既定はアプリアイコンの背景色(#0F4C5C)です。黄色や薄い色を選ぶと、読みやすい濃さに自動で調整します。
Lite と Advanced は同じ画面です。上部・帯・データセット一覧・グラフのカード・プロパティの位置とデザインは変わらず、Advanced では項目とグラフの下のパネルが足されるだけです。グラフの道具だけは、Lite は左に浮くアイコン、Advanced はプロットエリアの上に文字付きで並べます。「点線で強調」にすると、Advanced で増える部分が分かります。
