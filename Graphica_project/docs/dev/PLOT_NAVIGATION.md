# プロット表示部分のマウス操作の見直し(2026-10-03〜)

ブランチ `feature/plot-navigation`。マウス操作の現状調査から出た改善候補と、新しい操作体系の作業計画。

## 決まった操作体系(ユーザー決定 2026-10-03)

| 場所 | 操作 | 挙動 |
|---|---|---|
| 軸の上(目盛りラベルの帯) | ホイール | その軸だけをカーソル位置を中心に拡大・縮小 |
| 軸の上 | 左ドラッグ | その軸の方向だけに移動 |
| 軸の上 | 左ダブルクリック | その軸の範囲をリセット(最小・最大を設定していればその値、自動なら全体) |
| プロット内 | 左ドラッグ(どのモードもOFFのとき) | 矩形ズーム。凡例をつかんだときは凡例のドラッグ |
| プロット内 | 右クリック(右クリックを使うモード以外) | そのサブプロットの、1つ前の矩形ズームの前の範囲に戻す |
| プロット内 | 左ダブルクリック(左クリックを使うモード以外) | そのサブプロットの X・Y・Y2 をすべてリセット |
| プロット内 | 中ボタンのドラッグ | パン(直して残す) |
| プロット内 | ホイール | 廃止(ズームは矩形ズームだけ) |

- 右クリックで戻すのは矩形ズームだけ(軸のホイール・ドラッグ・リセットは戻さない)。履歴はサブプロットごと。
- matplotlib 標準のツールバーは廃止し、ホーム・戻る・進む・パン・ズーム・サブプロット調整・軸と曲線の編集・
  画像として保存のボタンを消す。独自のボタン(モード・統計・表示をリセット)は残す。
- 右クリックを使うモード: 注釈・ピーク配置・領域ハイライト。左クリックを使うモード: データカーソル・注釈・
  ピーク配置・レイアウト編集。どちらも `gui/tools/manager.py` の `MOUSE_MODES` の列で持つ。
- 以前の #84(プロット上のダブルクリックでリセット)は凡例のドラッグなどと重なって取り下げた。今回は凡例の上と、
  左クリックを使うモードの最中には反応しない。

## 作業計画(コミットの単位)

1. 表示範囲の計算(軸の帯の当たり判定、ピクセル基準のズーム・移動、設定どおりの範囲へのリセット)を
   `gui/tools/view_navigation.py` に新設。範囲の当て方は描画と同じ関数(`rendering/appearance.apply_axis_range`)を通す。
2. マウスの配線: 軸のホイール・ドラッグ・ダブルクリック、矩形ズームと右クリックで戻す、プロットのダブルクリック、
   中ボタンのパン(ピクセル基準に直す)。プロット内のホイールズームと旧パンを削除。
3. ツールバーを `QToolBar` に置き換え、matplotlib のボタンと、その日本語化・アイコン更新のコードを削除。
4. テスト(新しい操作の単体テスト、消した機能のテストの整理、UI 構造の基準の更新)、README の操作説明。

## 改善候補リスト(現状調査より)

状態: ✅ このブランチで解消 / ⏳ 未着手

| # | 内容 | 状態 |
|---|---|---|
| 1 | 中ボタンのパンがカーソルについてこない(データ座標の基準がずれて移動量が約半分・1回おきに止まる) | ✅ ピクセル基準に直す |
| 2 | 標準ツールバーのパン/ズームが独自モードと排他になっていない | ✅ 標準のパン/ズームごと廃止 |
| 3 | 凡例のドラッグとモードのドラッグ(注釈・範囲選択・領域ハイライト)が同時に起きうる | ⏳ 矩形ズームだけは凡例を避ける。各モードは未対応 |
| 4 | 第2軸のあるプロットで、ホイールズーム・パンが第2軸側だけにかかる | ✅ サブプロット単位で X・Y・Y2 を扱う |
| 5 | ホイールズーム・パンが対数軸を考えていない | ✅ ピクセル基準の計算で対数・反転にも対応 |
| 6 | ホイールズーム・パンを戻せない。ホームと「表示をリセット」が重複し、ホームは描き直し後に効かない | ✅ 右クリックで戻す・ダブルクリックでリセット・ホーム削除 |
| 7 | データカーソルの「近い点」がデータ座標の距離で選ばれる(X と Y の桁が違うと偏る)。棒グラフ・2D マップに未対応 | ⏳ |
| 8 | ステータスバーの座標はウォーターフォールのずらしを戻さない表示座標で、データカーソルと値が違う | ⏳ |
| 9 | ドラッグ中のプレビューが、範囲選択は blit、スライス抽出・領域ハイライトは毎回全体の描き直しで重い | ⏳ |
| 10 | 軸の外で離したときの扱いがモードでばらばら(黙って取り消し/図の外で確定) | ⏳ |
| 11 | 操作できる場所でマウスカーソルの形が変わらない | ✅ 軸の帯の上で変える(各モードは未対応) |
| 12 | 目盛り間隔を固定した軸を大きく縮小すると、`_safe_multiple_locator` は描画時の範囲でしか間引かないので目盛りが多すぎになりうる | ⏳ |
| 13 | 範囲を変えても、描き直し(データセットの設定の変更など)のたびに設定どおりの範囲へ戻る | ⏳ 仕様として扱うか要相談 |
