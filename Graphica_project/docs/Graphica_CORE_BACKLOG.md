# Graphica 本体実装バックログ

2つの100件提案(前回レビュー案 / Gemini案)を統合・重複排除し、**本体(Graphica本体コード)で実装すべきもの**を抽出したリスト。全135件。
プラグイン側は `Graphica_PLUGIN_BACKLOG.md`、振り分けの根拠は `Graphica_INTEGRATION_REPORT.md` を参照。

## 凡例

- **難**: ★☆☆ 既存機構への追加のみ / ★★☆ 新しい構造・UIが必要 / ★★★ アーキテクチャに影響
- **工数**: S 〜1日 / M 2〜5日 / L 1〜3週 / XL 1ヶ月〜
- **効果**: ◎ 大半のユーザーが日常的に使う / ○ 使う人が多い / △ ニッチだが刺さる
- **出典**: A 前回レビュー案 / B Gemini案 / AB 両者に存在
