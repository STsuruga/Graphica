# 行動規範 / Code of Conduct

[日本語](#日本語) | [English](#english)

## 日本語

### 目的

Graphica は、研究や実験に取り組む人が気持ちよく使い、改善に参加できるプロジェクトを目指しています。
経験の多少、専門分野、国籍、年齢、性別、性自認、障害の有無、外見、人種、宗教などにかかわらず、
誰もが敬意をもって扱われる場にするため、この行動規範を定めます。

この行動規範は、Issues、Pull Request、Wiki、Discussions など、このプロジェクトに関わる
すべての場所でのやり取りに適用されます。

### 望ましい行動

- 相手の立場や経験の違いを尊重し、丁寧な言葉を使う
- 意見の違いには、人ではなく内容に向けて建設的に伝える
- 初めて参加する人や、質問する人を歓迎する
- 自分の誤りを認め、そこから学ぶ
- 不具合の報告や要望には、再現手順など相手が対応しやすい情報を添える

### 許されない行動

- 差別的な発言、侮辱、人格攻撃、嫌がらせ
- 性的な表現や、望まれない性的な注目
- 他人の個人情報(住所、メールアドレスなど)を本人の許可なく公開すること
- しつこく付きまとう、脅す、威圧する
- 議論を意図的に妨げる投稿や、スパム

### 報告と対応

行動規範に反する行為を見かけた場合や、被害を受けた場合は、次のいずれかの方法で知らせてください。

- 該当する投稿やコメントの「…」メニューにある **Report content**(GitHub への報告)
- 公開の場で書きにくい場合は、Issue に「行動規範について非公開で連絡したい」とだけ書いてください。
  メンテナーから連絡方法をお知らせします(内容は書かないでください)

報告は、報告者のプライバシーに配慮して扱います。メンテナーは状況に応じて、注意、投稿の編集や削除、
一時的または恒久的な参加の制限を行うことがあります。

### 参考

この行動規範は [Contributor Covenant](https://www.contributor-covenant.org/) を参考に、このプロジェクト向けに
簡潔にまとめたものです。

## English

### Purpose

Graphica aims to be a project that people doing research and experiments can use comfortably and help improve.
This code of conduct exists so that everyone is treated with respect, regardless of experience, field, nationality,
age, gender, gender identity, disability, appearance, race, religion or any other characteristic.

It applies to every interaction in this project's spaces, including Issues, Pull Requests, the Wiki and Discussions.

### Expected behavior

- Respect differing viewpoints and experience, and use considerate language
- Direct disagreement at ideas, not people, and keep it constructive
- Welcome newcomers and people asking questions
- Acknowledge your own mistakes and learn from them
- When reporting a problem or requesting a feature, include information (such as steps to reproduce) that makes it
  easier for others to help

### Unacceptable behavior

- Discriminatory remarks, insults, personal attacks or harassment
- Sexualized language or unwelcome sexual attention
- Publishing others' private information (such as addresses or email) without their explicit permission
- Stalking, threats or intimidation
- Deliberately disrupting discussions, or spam

### Reporting and enforcement

If you see or experience behavior that violates this code of conduct, please let us know in either of these ways:

- Use **Report content** in the "…" menu of the post or comment (reports it to GitHub)
- If you would rather not describe it in public, open an issue saying only that you would like to contact the
  maintainer privately about the code of conduct; the maintainer will reply with a way to reach them. Please do not
  include the details in the issue.

Reports are handled with respect for the reporter's privacy. Depending on the situation, the maintainer may issue a
warning, edit or remove content, or temporarily or permanently restrict participation.
