# Graphica 取扱説明書

## 1. 概要

Graphica は、CSV/Excelファイルからデータを読み込み、グラフを作成・編集・エクスポートするためのソフトウェアです。複数のデータセットの同時表示、サブプロット、曲線フィッティング、ピーク検出、データ編集など、科学技術分野でのデータ可視化に役立つ多くの機能を備えています。

バージョン番号は、ヘルプメニューの「Graphica について...」で確認できます。

---

## 2. 基本的な使い方

### 2.1 ファイルの読み込み

1.  メインウィンドウ上部の **[データ追加]** ボタンをクリックします。
2.  ファイル選択ダイアログが開くので、読み込みたいCSVファイル (`.csv`)、テキストファイル (`.txt`)、またはExcelファイル (`.xlsx` / `.xls`) を選択します。
    * **注意:** CSV/テキストファイルの文字コードは自動判定されます (UTF-8 (BOM有無問わず) / Shift_JIS(CP932) / それ以外の順に判定を試みます)。Excelファイルは先頭シートが読み込まれます。
3.  列数の多いファイルの場合、読み込んだデータのプレビューが表示され、X軸・Y軸に使う列をその場で選択できます。プレビューを確認せず進めると、先頭2列が自動的に割り当てられます。
4.  ファイルが読み込まれると、「データセットリスト」に項目が追加され、グラフが描画されます。大きなファイルでもメイン画面がフリーズしないよう、読み込みはバックグラウンドで行われます。

### 2.2 画面構成

* **中央**: グラフ表示エリアとMatplotlibツールバー（ズーム、移動、データカーソルなど）。
* **左側**:
    * **データセットリスト**: 読み込んだデータセット（プロット）の一覧。フォルダで階層的に整理できます (2.4節参照)。
    * **データ操作ボタン**: `[データ追加]`, `[データ削除]`, `[プロット複製]`, `[データ表示/編集]`, `[曲線フィット]`, `[ピーク検出]`, `[新しいフォルダ]`, `[自動配色]`。
    * **プロパティ**: データセットリストで選択中のプロットの外観や設定を変更するエリア。
* **右側 (ドックウィジェット)**:
    * **プロット制御パネル**: グラフ全体の外観（軸、ラベル、グリッドなど）を設定するタブ付きパネル。

### 2.3 データセットの操作

* **削除**: データセットリストで削除したい項目を選択し、**[データ削除]** ボタンを押します。フォルダを削除すると、中身のデータセットもまとめて削除されます。
* **複製**: リストで項目を選択し、**[プロット複製]** ボタンを押すと、同じデータソースを持つプロットのコピーがリストに追加されます。これは、同じファイルの異なる列を同時にプロットしたい場合に便利です。
* **複数選択**: `Ctrl`/`Shift` を押しながらクリックすると複数のデータセットを選択でき、色・線種・削除などの操作をまとめて適用できます。
* **並べ替え**: データセットリスト上で項目をドラッグ&ドロップすると、グラフの描画順（前面/背面）を変更できます。同じフォルダ内での並べ替えは Undo (`Ctrl+Z`) で元に戻せます。

### 2.4 フォルダによるグループ分け

データセットが増えてきた場合、フォルダで階層的に整理できます。

* **[新しいフォルダ]** ボタン、またはデータセットリストを右クリック→「新しいフォルダ」でフォルダを作成します。
* データセットやフォルダをドラッグ&ドロップして、フォルダの中に移動できます（フォルダの中への移動は入れ子にも対応しています）。
* フォルダ自体はプロットを持たず、あくまでリスト上の整理のためのものです。

## 3. プロットの外観設定 (プロット制御パネル)

右側の「プロット制御パネル」で、現在「編集対象のプロット」で選択されているサブプロットの外観を設定します。

### 3.1 X軸 / Y軸 タブ

* **範囲**: 軸の最小値・最大値を手動で設定します。「自動スケール」にチェックを入れると、データに合わせて自動調整されます。数値欄には `1e-5` のような指数表記でも直接入力できます。
* **表示**: 「対数表示」でログスケールに、「軸を反転」で軸の向きを逆にします。
* **目盛**:
    * **主目盛**: 「自動」または「固定間隔」を選択できます。「固定間隔」を選んだ場合、下の「間隔」ボックスに数値を入力します（指数表記も可）。極端に小さい間隔を指定した場合は、目盛りが大量発生して描画が固まらないよう自動的に上限が設けられます。
    * **補助目盛**: 「補助目盛を表示」にチェックを入れると、補助目盛が表示されます。「間隔」で表示間隔を調整できます。

### 3.2 ラベル/書式 タブ

* **レイアウト (サブプロット有効時)**:
    * **グラフ全体レイアウト**: ウィンドウ内に表示するサブプロットの行数と列数を指定します。
    * **編集対象のプロット**: 設定を変更したいサブプロットをドロップダウンから選択します。
* **ラベル**:
    * **タイトル**: グラフのタイトルを入力します。
    * **X軸/Y軸/第2Y軸ラベル**: 各軸のラベルを入力します。第2Y軸ラベルは、第2Y軸が使用されているときのみ表示・有効になります。
    * **`mathtext`**: ラベルには `` `$\alpha$` `` → α や `` `$10^3$` `` → 10³, `` `$\mathbf{Bold}$` `` のようなLaTeX風の記法 (mathtext) を使って、特殊文字や書式設定を含めることができます（詳細はヘルプメニュー参照）。
* **書式**:
    * **目盛数値/軸ラベル**: **[フォント...]**, **[色...]** ボタンで、それぞれのフォントファミリー、サイズ、スタイル（太字/イタリック）、色を変更できます。
    * **目盛の太さ/向き**: 目盛線の太さと、グラフの内側(`in`)・外側(`out`)・交差(`inout`)どちらに向けるか（主/補助それぞれ）を設定します。
    * **凡例**: 「凡例を表示」で表示/非表示を切り替え、「凡例の位置」で表示場所を指定します。凡例は**マウスでドラッグして移動**することも可能です。
    * **グリッド**: 「グリッドを表示」で主グリッドの表示/非表示を切り替え、「補助グリッドの表示」で補助グリッドの表示/非表示を切り替えます（主グリッド表示中のみ有効）。
    * **外枠**: グラフの枠線の太さと色を設定します。

### 3.3 ダークモード

「表示」メニューの「ダークモード」にチェックを入れると、アプリ全体の配色とグラフの配色が両方ともダークテーマに切り替わります。設定は次回起動時にも引き継がれます。

## 4. データセットの個別設定 (プロパティ欄)

左下の「プロパティ」欄で、データセットリストで選択中の**個別**のデータセット（プロット）に関する設定を行います。複数選択している場合、変更した項目だけが選択中の全データセットに一括で適用されます。

* **凡例名**: 凡例に表示される名前を編集します。編集後、Enterキーを押すか、フォーカスを外すと反映されます。
* **X軸/Y軸の列**: このプロットに使用するデータの列をドロップダウンから選択します。
* **誤差(エラーバー)の列**: X軸・Y軸それぞれについて、誤差の値を持つ列を指定するとエラーバー付きで描画されます。「(なし)」を選ぶとエラーバーは非表示になります。
* **描画先プロット**: サブプロット機能使用時、このデータセットをどのサブプロットに描画するか選択します。
* **種類**: プロットの種類（`Line`, `Scatter`, `Line+Scatter`）を選択します。
* **色**: **[色を選択...]** ボタンでプロットの色を変更します。複数選択時は **[自動配色]** ボタンで、matplotlibの標準カラーサイクルに沿った色を選択中の全データセットへ順番に自動割り当てできます。
* **線の種類/太さ**: 線のスタイル（`solid`, `dashed`など）と太さを設定します（「種類」がLineまたはLine+Scatterの場合）。
* **マーカー/マーカーサイズ**: マーカーの種類（`o`, `s`, `^`など）とサイズを設定します（「種類」がScatterまたはLine+Scatterの場合）。
* **平滑化**: チェックを入れると、線プロットが滑らかな曲線（スプライン補間）で描画されます。
* **第2Y軸 (右側) を使用**: チェックを入れると、このデータセットはグラフ右側の第2Y軸のスケールでプロットされます。
* **フィット情報**: このデータセットが曲線フィットの結果である場合、フィットに使われた関数と計算されたパラメータが表示されます。

これらの変更はすべて「編集」メニュー (`Ctrl+Z` / `Ctrl+Y`) でUndo/Redoできます。

## 5. 高度な機能

### 5.1 データ編集 ([データ表示/編集]ボタン) 📝

1.  データセットリストで編集したいデータを選択し、**[データ表示/編集]** ボタンを押します。
2.  別ウィンドウが開き、データが表形式で表示されます。
3.  **セル編集**: セルをダブルクリックして値を直接編集できます。空にすると `NaN` (Not a Number) として扱われます。
4.  **行列操作**:
    * **[行を追加]**: 末尾に空の行を追加します。
    * **[選択行を削除]**: テーブルで選択中の行を削除します。
    * **[列を追加]**: 新しい列名を入力し、空の列を追加します。
    * **[選択列を削除]**: テーブルで選択中の列を削除します（プロットやエラーバーに使用中の列は削除できません）。
5.  **列計算**: **[列の計算...]** ボタンを押すと、`A + B * 2` や `log(A)` のような式を使って新しい列を計算したり、既存の列を上書きしたりできます。「移動平均」「差分」「正規化」「累積和」のプリセットボタンから、よく使う計算をワンクリックで適用することもできます（詳細はヘルプメニュー参照）。
6.  **CSV保存**: **[CSVとして保存...]** ボタンで、編集後のデータを新しいCSVファイルとして保存できます。
7.  **Undo/Redo**: 「編集」メニューまたはショートカットキー (`Ctrl+Z` / `Ctrl+Y`) で、セル編集や行列操作を元に戻したり、やり直したりできます。
8.  **閉じる**: ウィンドウ右下の **[Close]** ボタンで閉じます。編集内容は自動でメインウィンドウのグラフに反映されます。

### 5.2 曲線フィット ([曲線フィット]ボタン) 📈

1.  データセットリストでフィットさせたいデータを選択し、**[曲線フィット]** ボタンを押します。
2.  ダイアログでフィットしたい関数の種類（線形、多項式、指数関数など）を選択し、**[OK]** を押します。
3.  フィッティングが実行され、結果のパラメータが非モーダルのウィンドウに表示されます（グラフを操作しながら結果を確認できます）。結果は **[コピー]** ボタンでクリップボードにコピーするか、**[CSVとして保存]** ボタンでファイルに出力できます。
4.  元のグラフに、フィット結果の曲線が**破線**で新しいデータセットとして（元データと同じフォルダ内に）追加されます。
5.  追加されたフィット曲線のデータセットを選択すると、「プロパティ」欄の「フィット情報」でパラメータを再確認できます。

### 5.3 ピーク検出 ([ピーク検出]ボタン) ⛰️🏞️

1.  データセットリストでピークを探したいデータを選択し、**[ピーク検出]** ボタンを押します。
2.  ダイアログで検出タイプ（**上に凸/下に凸**）と感度パラメータ（**最小高さ、最小距離、突出度**）を設定し、**[OK]** を押します。
    * **注意:** 「下に凸 (Valleys)」の場合、「最小高さ」は反転データに対するピーク高を指定します (ヘルプ参照)。
3.  検出されたピーク（または谷）の位置に、グラフ上に**マーカー**（赤の▼ / 青の▲）が新しいデータセットとして追加されます。
4.  検出されたピーク/谷のX, Y座標リストが非モーダルのウィンドウに表示されます。フィット結果と同様、コピーやCSV保存ができます。

### 5.4 データカーソル (ツールバーの → ボタン) 🎯

1.  Matplotlibツールバー（グラフの下）にある **[→]** （データカーソル）ボタンをクリックして有効にします（ボタンが押された状態になります）。
2.  グラフ上にマウスカーソルを移動させると、メインウィンドウ右下の**ステータスバー**にリアルタイムでカーソル位置のグラフ座標が表示されます。
3.  グラフ上の線や点をクリックすると、その近くにある**データ点の正確な (X, Y) 座標**が、黄色い吹き出しでグラフ上に表示されます。
4.  再度 **[→]** ボタンを押すと、モードが無効になります。

### 5.5 プラグイン 🧩

Graphica はプラグインによる機能拡張に対応しています。プラグインは、データの読み込み/書き出し形式の追加、データ処理・解析の追加、曲線フィット関数の追加、独自パネルの追加などができます。

* **プラグインの管理**: メニューの「環境設定」→「プラグイン」タブで、読み込まれているプラグインの一覧・有効/無効の切り替え・エラー内容の確認ができます。
* **プラグインの配置**: ソースから実行している場合は `plugins/` フォルダに、実行ファイル(exe)版の場合は実行ファイルと同じ階層のプラグイン用フォルダに、プラグインのフォルダを配置します。配置後はGraphicaの再起動が必要です。
* **プラグイン開発**: 独自プラグインの作り方は `docs/plugin_development.md`(開発者向けドキュメント)を参照してください。

## 6. ファイル操作 (メニューバー)

### 6.1 ファイル メニュー

* **プロジェクトを開く**: 以前に保存した `.graphica` プロジェクトファイルを読み込み、データと設定（フォルダ構成を含む）を復元します。旧バージョンで保存した `.pkl` ファイルも引き続き開けます。
* **プロジェクトを保存**: 現在の状態（読み込んでいる全データ、フォルダ構成、グラフ設定）を `.graphica` ファイルに保存します。後で「プロジェクトを開く」で再開できます。
* **最近使ったファイル**: 直近に開いた・保存したプロジェクトファイルの一覧から、すばやく開き直せます。
* **書式テンプレートを保存**: 現在のグラフの**外観設定のみ**（軸ラベル、フォント、色、レイアウトなど、データは除く）を `.json` テンプレートファイルとして保存します。
* **書式テンプレートを適用**: 保存したテンプレートファイルを読み込み、現在のグラフにその外観設定を適用します。
* **名前を付けてエクスポート**: 現在表示されているグラフを画像ファイル（PNG, PDF, SVG）として保存します。サイズや解像度を指定できます。
* **オートセーブ間隔を設定**: 自動保存の間隔（分単位）を変更します。`0`にすると自動保存を無効化できます。現在の間隔はメニュー上に表示されます。

### 6.2 編集 メニュー

* **元に戻す / やり直し**: データ編集、プロパティ変更、並べ替えなどの操作をUndo/Redoします (`Ctrl+Z` / `Ctrl+Y`)。

### 6.3 表示 メニュー

* **プロット制御パネル / データセットプロパティ**: 各ドックウィジェットの表示/非表示を切り替えます。
* **ダークモード**: アプリ全体とグラフの配色をダークテーマに切り替えます。

### 6.4 ヘルプ メニュー

* **mathtext リファレンス**: 軸ラベルなどで使える特殊文字や書式の書き方 (mathtext) のリファレンスを表示します。
* **列計算機能 リファレンス**: データ編集ウィンドウの「列の計算」機能で使える演算子や関数のリファレンスを表示します。
* **Graphica について**: バージョン番号と、使用しているオープンソースライブラリの一覧を表示します。

## 7. 開発者向け: 自動テストの実行

`core/` (データ処理・曲線フィット・Undo/Redo・プロジェクトの保存/読込) を中心に、
`tests/` ディレクトリに pytest ベースの自動テストを用意しています。
機能を追加・変更したときに、既存のロジックが壊れていないかを自動で確認できます。

```
pip install -r requirements.txt   # pytest を含む依存パッケージをインストール
pytest                            # Graphica_project ディレクトリで実行
```
